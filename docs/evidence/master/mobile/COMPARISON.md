# Baseline (0e92384) vs Current (HEAD) Responsive & Styling Comparison

This document records the exact differences between commit `0e92384` (the first stable deploy whose mobile rendering was verified good on real devices) and `HEAD` across styling, layout, components, and responsive behaviors.

## Decision Legend
- **RESTORE**: A mobile/base style (unprefixed classes and `sm:`) that differs from the old version and had a mobile effect. Put the old value back in the current markup.
- **KEEP**: Current features, content, structure, translations, desktop styles (`md:`, `lg:`, `xl:` classes), and desktop fixes made after the first deploy.
- **MERGE**: The markup changed (new elements). Apply the old mobile behavior to the equivalent current element: copy the old base/`sm:` classes and layout approach (grid/flex direction, gaps, paddings, container widths, font sizes, order) and keep the current `md:`+ classes.
